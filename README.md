# agentic-github-flow

One working method for AI coding agents on GitHub, in a team that works with pull requests or
alone on a repository of your own, for **Claude Code** and **Codex** alike: short rules that load
in every session, and skills that load only when a task needs them. You install it with one
command and write no instruction files of your own.

agentic-github-flow is unrelated to `ruvnet/agentic-flow` and its npm package.

## Start here

- **What it is and what you can do with it:** [docs/guide.md](docs/guide.md), for anyone who
  uses an AI coding agent: what changes in your daily work, what you can ask for, the opt-in
  parts, and using it at work.
- **Installing it:** [docs/install.md](docs/install.md), written for the agent that installs it.
  Ask your agent: *"Install agentic-github-flow for me: clone
  https://github.com/IgorVerm/agentic-github-flow.git to ~/.agentic-github-flow and follow
  docs/install.md there."* It checks the requirements, asks you the decisions, installs and
  verifies. Updating and removing it are in the same guide.
- **Changing this repository:** [AGENTS.md](AGENTS.md) and [HANDOFF.md](HANDOFF.md).

macOS, Linux and Windows; repositories on github.com.
